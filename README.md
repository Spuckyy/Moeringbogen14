# Möringbogen 14

Ein First-Person-Horrorspiel über eine Kindheit in einem Hamburger Hochhaus.

Du kehrst nach fast dreißig Jahren an den Möringbogen 14 in Hamburg-Alsterdorf zurück. Das Hochhaus steht leer und
wird bald abgerissen, und hier bist du aufgewachsen. Du kommst mit der U1 an, gehst vom Bahnhof U Alsterdorf zum Haus
und suchst dir Stockwerk für Stockwerk den Weg zurück zu dem, was damals passiert ist.

Sechs Kapitel, drei Enden. Keine Waffen, keine Kämpfe. Eine Taschenlampe, dein Gedächtnis und das Telefon.

> **Early Access 0.4.1.** Das Spiel ist noch in Arbeit. Es kann Fehler enthalten, und Inhalte können sich ändern.

## Inhaltshinweis

Das Spiel handelt von häuslicher Gewalt, Kindheitstrauma und dem Tod eines jungen Menschen durch Drogen. Gewalt wird
nicht gezeigt. Wenn dich das Thema belastet:

- Hilfetelefon Gewalt gegen Frauen: **116 016**
- Nummer gegen Kummer: **116 111**
- TelefonSeelsorge: **0800 111 0 111**

Diese Nummern sind echt und rund um die Uhr kostenlos erreichbar.

## Download und Start

1. Lade unter [Releases](../../releases/latest) **beide** Teile herunter:
   `Moeringbogen14_EarlyAccess_0.4.1.7z.001` und `Moeringbogen14_EarlyAccess_0.4.1.7z.002`.
   GitHub erlaubt höchstens 2 GB pro Datei, deshalb ist das Spiel geteilt.
2. Lege beide Dateien in denselben Ordner.
3. Entpacke **`.7z.001`** mit [7-Zip](https://www.7-zip.org/) (kostenlos). Der zweite Teil wird dabei automatisch
   mitgenommen.
4. Starte `Moeringbogen14.exe`.

Beim ersten Start installiert Windows eventuell die benötigten Laufzeitbibliotheken. Die Spielanleitung liegt als
`Anleitung.pdf` im Spielordner und hier als eigener Download im Release.

## Systemvoraussetzungen

- Windows 10 oder 11 (64 Bit)
- Grafikkarte mit DirectX 12
- etwa 2,5 GB freier Speicherplatz, das Spiel braucht rund 3 GB Arbeitsspeicher

Entwickelt und getestet mit einer NVIDIA GeForce RTX 4070 und 32 GB RAM. Mindestanforderungen sind noch nicht ermittelt.

## Steuerung (Kurzfassung)

| Aktion | Tastatur / Maus |
|---|---|
| Gehen / Umsehen | W A S D / Maus |
| Rennen / Vorsichtig gehen | Shift / Strg oder C |
| Springen | Leertaste |
| Benutzen | E oder linke Maustaste |
| Taschenlampe / Batterie wechseln | T oder F / R |
| Prüfgerät (EMF) | G |
| Inventar / Dokumente / Aufgaben | Tab / J / L |
| Pause | Esc |
| Schnellspeichern / -laden | F5 / F9 |

Gamepad wird unterstützt. Die ganze Steuerung, alle Funktionen und die Telefonnummern im Spiel stehen in der Anleitung.

## Fehler melden

Fehler und Vorschläge bitte als [Issue](../../issues) melden: was du gemacht hast, wo im Spiel du warst und, wenn
möglich, ein Screenshot. Nach einem Absturz liegt ein Bericht unter
`%LOCALAPPDATA%\Moeringbogen14\Saved\Crashes`.
